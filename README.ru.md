<h1 align="center">KeySwitch</h1>

<p align="center">
  <b>Набрали <code>ghbdtn</code> — получили <code>привет</code>.</b><br>
  Бесплатный нативный Punto Switcher для macOS. Без аккаунта, без сети, без телеметрии.
</p>

<p align="center">
  <a href="README.md">Read in English</a>
</p>

KeySwitch живёт в строке меню и исправляет текст прямо во время набора. Слово в неправильной
раскладке он переводит в правильную, сам переключает раскладку и попутно убирает десяток
мелких неудобств. Любое исправление отменяется двойным нажатием Shift.

## Установка

```sh
brew install --cask andrewkomkov/tap/key-switch
open -a KeySwitch
```

После запуска выдайте разрешение «Универсальный доступ» в открывшемся окне. Это всё.

Нужна macOS 26 или новее, одна английская и одна русская раскладка в Системных настройках.

| Задача | Команда |
| --- | --- |
| Обновить | `brew upgrade --cask key-switch` |
| Удалить программу | `brew uninstall --cask key-switch` |
| Удалить программу и её данные | `brew uninstall --cask --zap key-switch` |

Перед обновлением Homebrew закрывает программу. После обновления откройте её снова.
Разрешение сохраняется: у всех релизов одна подпись.

Без Homebrew:

1. Скачайте `KeySwitch.zip` со страницы [релизов](https://github.com/andrewkomkov/key-switch/releases).
2. Перенесите `KeySwitch.app` в папку «Программы».
3. Снимите метку карантина: `xattr -dr com.apple.quarantine /Applications/KeySwitch.app`.
4. Откройте программу.
5. Выдайте разрешение «Универсальный доступ».

Шаг 3 нужен, потому что релиз подписан самоподписанным ключом без нотаризации Apple.
Homebrew делает этот шаг сам.

## Что умеет

| Вы делаете | Получаете | По умолчанию |
| --- | --- | --- |
| Набираете `ghbdtn` или `руддщ` и пробел | `привет` или `hello`, раскладка переключается | Вкл. |
| Дважды нажимаете Shift | Последнее слово или выделенный текст в другой раскладке | Вкл. |
| Один раз нажимаете Shift | Следующая раскладка | Вкл. |
| Дважды нажимаете Option | `hello`, `Hello`, `HELLO` | Вкл. |
| Набираете `ПРивет` | `Привет` | Вкл. |
| Набираете `:fire:` и пробел | Эмодзи огня в любой программе. 1913 кодов GitHub | Вкл. |
| Набираете замену текста из настроек macOS, например `omw` | `On my way!` — и в Chrome, и в Electron-программах, и в терминале | Вкл. |
| Нажимаете Command-Shift-V | Вставка без форматирования | Вкл. |
| Нажимаете Control-Option-V | Поиск по истории буфера обмена, Return вставляет запись | Выкл. |
| Набираете `севодня` или `recieve` | `сегодня` или `receive` | Выкл. |
| Набираете `еще` | `ещё` | Выкл. |
| Набираете `Привет. как` | `Привет. Как` | Выкл. |

Каждая функция включается и выключается в настройках. Отмена у всех автоматических
исправлений одна: дважды нажмите Shift. Набранное слово вернётся и попадёт в исключения,
так что второй раз KeySwitch его не тронет.

## Жесты

- **Shift** — следующая раскладка.
- **Shift дважды** — последнее слово заново в другой раскладке. Каждое следующее нажатие в
  той же серии захватывает ещё одно слово слева.
- **Shift дважды после автоисправления** — вернуть слово как было и добавить его в исключения.
- **Option дважды** — сменить регистр последнего слова.
- **Command-Shift-V** — вставить текст без форматирования.
- **Control-Option-V** — поиск по истории буфера.

Shift и Option работают и с выделенным текстом: выделите его и сделайте жест.

## История буфера обмена

По умолчанию выключена. Включается в настройках, вкладка «Буфер обмена».

- Хранит текст и картинки, от 10 до 100 записей, переживает перезагрузку.
- Записи видны в меню программы. Щелчок по записи кладёт её обратно в буфер.
- Control-Option-V или пункт «Поиск в истории…» открывает панель поиска.
- Option-щелчок по записи закрепляет её. Закреплённую запись не удаляют ни лимит, ни очистка.
- Пароли, которые менеджер паролей помечает как скрытые, в историю не попадают.

## Почему KeySwitch

- **Приватность.** Программа вообще не выходит в сеть. Клавиши текущего слова живут только
  в памяти и не попадают ни на диск, ни в журнал.
- **Точность.** Исправляет 96,9% русских слов в неправильной раскладке и ошибочно меняет
  0,05% правильных. Цифры считают тесты из этого репозитория.
- **Скорость.** Одно решение занимает около 15 микросекунд.
- **Простая отмена.** Ошибка стоит одного двойного нажатия и не повторяется.
- **Нативность.** Swift и SwiftUI, только системные библиотеки, около 6 МБ. Без Electron,
  без фоновых помощников, без регистрации.
- **Открытый код.** Лицензия MIT. У каждой функции есть спецификация в `specs/` и тесты.
